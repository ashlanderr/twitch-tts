# twitch-tts

Озвучка сообщений из чата голосами персонажей. Работает локально, без облачных сервисов.

Сообщение → базовый TTS (Silero для русского, Silero или Kokoro для английского) → RVC (тембр персонажа:
Сидорович, Артас, стражник из Skyrim…). Сообщения на смеси языков делятся по алфавиту, числа и ссылки
проговариваются словами.

- **Очередь без затыков**: следующее сообщение синтезируется, пока играет текущее; лишние выбрасываются,
  если чат пишет быстрее, чем успевает озвучка.
- **Мало видеопамяти**: на видеокарте держится только последний голос (~1,5–2 ГБ всего при любом числе
  голосов), а если видеопамяти мало (игра заняла), сообщение озвучивается на процессоре.
- **Два режима вывода звука**: на звуковую карту этого компьютера (например, в виртуальный кабель для OBS)
  или по сети в OBS на другом компьютере. Так можно вынести озвучку на отдельный ноутбук.
- **Тестовый чат** с веб-интерфейсом: десять симулированных зрителей и графики CPU/GPU/VRAM, чтобы
  проверить нагрузку рядом с игрой.

- **Чат Twitch** читается без аккаунта и токенов: достаточно названия канала. Озвучиваются все сообщения
  зрителей, кроме ботов; смайлы (Twitch, 7TV, BTTV, FFZ), ссылки и @ники вырезаются. Если модератор удалил
  сообщение или забанил автора, оно убирается из очереди, а если уже звучит, обрывается.

## Требования

- Python 3.12, видеокарта NVIDIA с 4 ГБ видеопамяти или больше (можно и без неё, но тогда ~2× медленнее
  реального времени).
- Windows 10/11 или Linux (Ubuntu).
- Модели голосов RVC (`.pth` и, желательно, `.index`) нужно найти самому, в репозитории их нет.

## Голоса

`voices/<имя>/model.pth`, `model.index` (необязательно) и `voice.json`:

```json
{ "pitch": 0, "ru_speaker": "eugene", "en_speaker": "am_michael", "en_silero_speaker": "en_0" }
```

- `pitch` — сдвиг в полутонах (+12 из мужского базового голоса в женский RVC-голос).
- `ru_speaker` — Silero: aidar, baya, kseniya, xenia, eugene.
- `en_speaker` — Kokoro: am_michael, am_adam, af_heart, …; `en_silero_speaker` — Silero EN: en_0 … en_117.
- `index_rate`, `protect` — параметры RVC.

Базовый голос лучше брать того же пола, что и RVC-голос. В репозитории лежат только `voice.json` для десяти
голосов, под которые настроен симулятор чата; файлы моделей положите рядом.

После добавления голоса сожмите его индекс: `python compact_index.py <имя>`. Векторы сохраняются в fp16, файл
`model.compact.index` вдвое меньше, на звук это не влияет. Голоса держатся в оперативной памяти (~90 МБ на
голос), на видеокарте только последний использованный.

Базовые модели (Silero, HuBERT, RMVPE, Kokoro) скачиваются сами при первом запуске: в `models/` и в кэш
Hugging Face.

## Установка: Windows

```
python -m venv .venv
.venv\Scripts\python -m pip install torch torchaudio torchvision --index-url https://download.pytorch.org/whl/cu126
.venv\Scripts\python -m pip install -r requirements.txt
```

## Установка: Linux (Ubuntu)

Основной способ на Linux: прямо в системе, через venv. Проверено на Zorin OS 17 (Ubuntu 22.04), RTX 3050
Laptop 4 ГБ: голоса, тестовый чат и звук в OBS на другом компьютере через `/overlay` работают.

Нужен драйвер NVIDIA 560 или новее (`nvidia-smi` должен показывать видеокарту). В Ubuntu 22.04 нет Python 3.12
в стандартных репозиториях, его даёт PPA deadsnakes: `sudo add-apt-repository ppa:deadsnakes/ppa`.

```
sudo apt install python3.12-venv python3.12-dev build-essential espeak-ng libportaudio2 libsndfile1
python3.12 -m venv .venv
.venv/bin/python -m pip install torch torchaudio torchvision --index-url https://download.pytorch.org/whl/cu126
.venv/bin/python -m pip install -r requirements.txt
```

Дальше в командах вместо `.venv\Scripts\python` пишите `.venv/bin/python`.

## Установка: Docker (Linux)

Запасной вариант, на реальной машине не проверялся. Нужны Docker и [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html).
Голоса берутся из `./voices`, скачанные модели сохраняются в `./models` и в томе `cache`.

```
docker compose up -d --build
docker compose logs -f        # первый запуск: загрузка моделей, ~1–2 мин
```

Дополнительные флаги `app.py` задаются в `command:` в `docker-compose.yml`, например `["--en-engine", "kokoro"]`.

## Отдельный компьютер для озвучки (звук в OBS по сети)

На компьютере с озвучкой (через Docker это режим по умолчанию):

```
python app.py --host 0.0.0.0 --output web
```

В консоли будут два адреса:

- `UI: http://192.168.x.x:8765` — интерфейс управления, открывается с любого компьютера в сети;
- `OBS Browser Source: http://192.168.x.x:8765/overlay` — страница, которая проигрывает озвучку.

В OBS на стримерском компьютере: **Источники → + → Браузер**, URL — адрес `/overlay`, включить
**«Управлять аудио через OBS»** (Control audio via OBS). Источник невидимый, громкость и фильтры настраиваются в
микшере OBS как у любого другого. Громкость можно задать и в адресе: `/overlay?volume=0.8`.

Пока ни одна страница `/overlay` не подключена, сообщения не озвучиваются (статус «нет оверлея»), чтобы
очередь не копилась. Если открыть `/overlay` в обычном браузере, нужно один раз нажать «Включить звук»:
браузеры не дают странице играть звук без клика, OBS даёт.

Интерфейс и `/overlay` доступны всем в локальной сети и без пароля. Не открывайте порт 8765 в интернет.

Компьютер с озвучкой лучше подключить кабелем или держать в той же Wi-Fi сети, что и стримерский. Если
страница не открывается, проверьте файрвол: `sudo ufw allow 8765/tcp`.

## Чат Twitch

```
python app.py --twitch-channel <канал>
python app.py --twitch-channel <канал> --twitch-ignore mybot,otherbot   # ещё боты, кроме известных
```

Подключение только на чтение (анонимный ник `justinfan…`), поэтому проверить можно на любом идущем стриме.
В чат приложение ничего не пишет. Не озвучиваются: известные боты (Nightbot, StreamElements, Moobot…),
команды другим ботам (сообщения с `!`), сообщения только из смайлов, ссылок и упоминаний.

Команды зрителей, как у jeetbot:

- `!tts arthas` — выбрать себе голос насовсем (хранится в `user_voices.json` по id зрителя, переживает
  перезапуск). Само сообщение не озвучивается.
- `!!!#bandit Эй, слышь` — одно сообщение другим голосом.

Без своего выбора у каждого зрителя постоянный голос по его id (или тот, что выбран в интерфейсе). Ник,
написанный в тексте без `@`, отличить от обычного слова нельзя, он будет прочитан.

## Запуск

```
python app.py                                    # тестовый чат: http://127.0.0.1:8765
python app.py --audio-device "CABLE Input"       # звук в виртуальный кабель (VB-CABLE) для OBS на этом же ПК
python app.py --host 0.0.0.0 --output web        # звук по сети, см. выше
python app.py --en-engine kokoro                 # английский через Kokoro: лучше звучит, +~0,5 ГБ видеопамяти
python app.py --rvc-device cpu                   # без видеокарты

python say.py -v sidorovich "Привет, сталкер! Welcome to the Zone"        # -> out.wav
python say.py -v sidorovich --play --audio-device "CABLE Input"           # интерактивно: строка = сообщение
python say.py --list-voices
python bench.py --rvc-device cuda                # скорость на этой машине
python memtest.py --label <имя>                  # память и скорость со всеми голосами
```

В поле ввода интерфейса работают те же команды, что и в чате: `!!!#bandit Эй, слышь`, `!tts arthas`. В `say.py` в
интерактивном режиме `голос: текст` переключает голос. На машине только для озвучки (без игры) имеет смысл
`--en-engine kokoro` и `--priority normal`.

Метрики ресурсов раз в секунду и журнал сообщений пишутся в `logs/`.

## Замеры

Сообщения 1–8 с, 4 потока torch, английский через Silero.

| машина, режим | на сообщение | видеопамять |
|---|---|---|
| RTX 3060 Ti 8 ГБ, Ryzen 7 2700, Windows — GPU: RVC на видеокарте, Silero на CPU | 0,25–1 с, смена голоса почти не добавляет | ~1,3 ГБ + ~0,4 ГБ CUDA-контекст |
| RTX 3060 Ti 8 ГБ, Ryzen 7 2700, Windows — CPU: RVC + Silero RU/EN | 3–16 с (~2× медленнее реального времени) | 0 |
| RTX 3050 Laptop 4 ГБ, Ryzen 7 5800H, Linux — GPU: RVC на видеокарте, Silero на CPU | 0,3–0,7 с, первое после смены голоса 0,9–1,5 с | ~0,85 ГБ + ~0,3–0,5 ГБ CUDA-контекст |

Kokoro добавляет ~0,5 ГБ видеопамяти. На RTX 3050 4 ГБ с десятью голосами оперативной памяти занято 5,2 ГБ,
запуск (загрузка моделей и прогрев) ~15 с.

## Файлы

| файл | что делает |
|---|---|
| `tts_pipeline.py` | базовый TTS, RVC, выгрузка голосов из видеопамяти, переход на CPU |
| `app.py` | веб-интерфейс, очередь озвучки, отдача звука в `/overlay` |
| `audio_player.py` | вывод звука: звуковая карта или сеть |
| `chat_sim.py` | симулятор зрителей |
| `twitch_chat.py` | чтение чата Twitch, смайлы 7TV/BTTV/FFZ; `python twitch_chat.py <канал>` печатает, что будет озвучено |
| `metrics.py` | замеры CPU/RAM/GPU/VRAM (Windows: счётчики производительности, Linux: NVML) |
| `say.py`, `bench.py`, `memtest.py`, `compact_index.py` | консольные утилиты |
| `static/index.html`, `static/overlay.html` | интерфейс и страница для OBS |
